**Course:** CPRO 1201 — Python Programming I
**Program:** Computer Programming
**Institution:** Red Deer Polytechnic

Topics covered may include:

* Python syntax and program structure
* Variables and data types
* Input and output
* Arithmetic, comparison, and logical operators
* Conditional statements
* Loops
* Strings
* Lists, tuples, and dictionaries
* Functions
* Basic problem solving
* Debugging and testing
* Introduction to object-oriented programming

## 🐍 Python Version

The examples in this repository are intended to run with Python 3.

You can check whether Python is installed by running:

```bash id="cpro1201-python-version"
python --version
```

or:

```bash id="cpro1201-python3-version"
python3 --version
```

## ▶️ Running a Python Program

Navigate to the folder containing the Python file and run it from the terminal:

```bash id="cpro1201-run"
python filename.py
```

For example:

```bash id="cpro1201-example"
python example.py
```

You can also run Python programs directly from your IDE or code editor.

## 🧪 Experiment With the Code

The examples in this repository are meant to be used as a starting point for learning.

You are encouraged to:

1. Run the examples.
2. Read the code carefully.
3. Change values and expressions.
4. Add your own code.
5. Make mistakes and investigate the errors.
6. Try to predict the output before running the program.

A good way to learn programming is to **write and experiment with code**, not simply read it.

## 🤔 When You Get Stuck

Programming is challenging, especially when learning it for the first time.

When a program does not work:

1. Read the error message.
2. Identify the line where the error occurred.
3. Check your syntax.
4. Check the values of your variables.
5. Try a smaller example.
6. Use debugging techniques to investigate the problem.
7. Ask questions when you need help.

Learning how to **find and fix your own errors** is an important programming skill.
